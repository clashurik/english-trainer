# English Trainer — правила проекта

Telegram Mini App для изучения английских слов: чистый HTML + JS без сборщиков, хостинг GitHub Pages из корня ветки `main`, прогресс в Telegram CloudStorage. Владелец проекта — новичок в программировании: объяснять по-русски, просто и по шагам.

## Неприкосновенное
- Поле `en` существующих карточек в `data/*.json` не менять никогда: от него считается id, к которому привязан прогресс пользователей. Удалять карточки тоже нельзя.
- Файлы сайта лежат в корне: `index.html`, `style.css`, `changelog.js`, `words.js`, `core.js`, `storage.js`, `app.js`. Пути без папок.
- `words.js` собирается из `data/*.json` командой `python3 tools/build_words.py`, руками не правится.

## Выпуск версии
1. Запись сверху в `changelog.js`. Нумерация: исправления 1.2.0 → 1.2.1, новые функции → 1.3.0.
2. Все `?v=` в `index.html` — на новый номер (иначе Telegram покажет старые файлы; `check.sh` сверяет).
3. `./check.sh` — сборка словаря, тесты логики, сквозной тест в браузере, превью. Всё должно пройти.
4. Коммит в `main` с понятным описанием по-русски, push, затем дождаться успешного «pages build and deployment» (`gh run list -R clashurik/english-trainer -L 1`).
5. Обновить превью-артефакт и roadmap.

## Команда агентов (`.claude/agents/`)
- `word-selector` — Отборщик: выбирает слова следующей порции словаря.
- `lexicographer` — Лексикограф: пишет и дополняет карточки по `data/SPEC.md`.
- `proofreader` — Корректор: независимо проверяет карточки, которые писал не он.
- `tester` — Тестировщик: перед выпуском ищет проблемы, код не правит.

Правила для параллельной работы: одна партия или один файл на агента, у каждого своя рабочая папка в scratchpad, общих скриптов нет. Результаты агентов всегда проверяются: автоматически (`build_words.py`) и Корректором.
