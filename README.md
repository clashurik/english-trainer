# English Trainer — Telegram Mini App

Тренажёр английских слов с интервальным повторением. Версия 1: 120 слов A1–B1, ежедневное занятие, серия дней, прогресс по уровням.

## Что в папке

| Файл | Зачем |
| --- | --- |
| `index.html` | Разметка всех трёх экранов: главный, занятие, итог |
| `style.css` | Внешний вид, светлая и тёмная тема |
| `words.js` | Словарь. Чтобы добавить слово, допишите строку по образцу |
| `core.js` | Логика повторения (SRS), очередь, серия дней. Без интерфейса |
| `storage.js` | Сохранение прогресса: облако Telegram или память браузера |
| `app.js` | Связывает кнопки на экране с логикой |
| `tests/` | Автотесты: логика (`core.test.js`) и прохождение занятия в браузере (`e2e.py`) |
| `tools/build_preview.py` | Собирает всё в один файл для превью |
| `check.sh` | Запускает все проверки одной командой |

## Запуск в Telegram (один раз, около 15 минут)

### Шаг 1. Выложить сайт на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com), если аккаунта нет.
2. Нажмите **+** справа вверху → **New repository**.
3. Имя: `english-trainer`. Выберите **Public** (бесплатный GitHub Pages работает только с публичными репозиториями). Нажмите **Create repository**.
4. На странице репозитория нажмите ссылку **uploading an existing file**.
5. Перетащите в окно **содержимое** распакованной папки (`index.html`, `style.css`, `app.js` и остальное; папки не нужны, всё лежит в корне), а не саму папку. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В блоке **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
7. Через 1–2 минуты сверху появится адрес вида `https://ВАШ_ЛОГИН.github.io/english-trainer/`. Откройте его в браузере и проверьте, что приложение работает.

### Шаг 2. Создать бота и привязать к нему приложение

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Введите отображаемое имя (например, `My English Trainer`), затем username, который заканчивается на `bot` (например, `my_english_trainer_bot`).
3. BotFather пришлёт **токен**. Никому его не показывайте и не вставляйте в код. В версии 1 он не нужен, понадобится в v3 для напоминаний.
4. Отправьте `/mybots` → выберите бота → **Bot Settings** → **Menu Button** → **Configure menu button**.
5. Пришлите адрес из шага 1, затем название кнопки, например `Учить`.
6. Откройте своего бота: слева от поля ввода появится кнопка **Учить**. Нажмите её — приложение откроется внутри Telegram, а прогресс будет храниться в облаке Telegram.

Если меню BotFather выглядит иначе, ищите пункты **Menu Button** или **Configure Mini App**: Telegram время от времени меняет интерфейс BotFather.

## Как обновлять

Замените изменённые файлы в репозитории (**Add file → Upload files**). GitHub Pages обновится за 1–2 минуты. Прогресс при этом не теряется: он хранится не в файлах, а в облаке Telegram.

## Проверка перед обновлением (для разработчика)

```sh
./check.sh
```

Нужны Node.js и Python с Playwright (`pip install playwright && python3 -m playwright install chromium`).
