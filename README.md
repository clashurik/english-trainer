# English Trainer — Telegram Mini App

Тренажёр английских слов с интервальным повторением: ежедневное занятие, свободная тренировка, слова из уроков, формы слов, история версий. Текущая версия и список изменений — в `changelog.js`.

## Что в папке

**Файлы сайта** — именно их загружаем в репозиторий GitHub:

| Файл | Зачем |
| --- | --- |
| `index.html` | Разметка всех экранов |
| `style.css` | Внешний вид, светлая и тёмная тема |
| `changelog.js` | Номер версии и история изменений |
| `words.js` | Словарь. Собирается автоматически из `data/`, руками не править |
| `core.js` | Логика повторения (SRS), очередь, серия дней, версии. Без интерфейса |
| `storage.js` | Сохранение прогресса: облако Telegram или память браузера |
| `app.js` | Связывает кнопки на экране с логикой |

**Файлы для разработки** — на сайт не нужны, но хранить их стоит:

| Файл | Зачем |
| --- | --- |
| `data/*.json` | Исходники словаря: одна карточка — один объект |
| `data/SPEC.md` | Формат карточки и требования к примерам |
| `tools/build_words.py` | Проверяет словарь и собирает `words.js` |
| `tools/build_preview.py` | Собирает всё в один файл для превью и сверяет номер версии |
| `tests/` | Автотесты: логика (`core.test.js`) и сценарии в браузере (`e2e.py`) |
| `check.sh` | Все проверки одной командой |

## Команда агентов

Помощники Claude, которые работают над проектом. Их роли и правила описаны в `.claude/agents/`, общие правила проекта — в `CLAUDE.md`.

| Роль | Файл | Что делает |
| --- | --- | --- |
| Отборщик | `word-selector.md` | Выбирает слова для следующей порции словаря и ставит их по полезности |
| Лексикограф | `lexicographer.md` | Пишет и дополняет карточки: перевод, примеры, формы, подсказки |
| Корректор | `proofreader.md` | Независимо проверяет чужие карточки и исправляет ошибки |
| Тестировщик | `tester.md` | Перед выпуском ищет проблемы в приложении, код не правит |

Чтобы поручить работу, достаточно написать Claude, например: «запусти Корректора на файл data/words-B1-1.json». Роль можно поменять, отредактировав её файл.

Уровни слов взяты из [CEFR-J Wordlist](https://github.com/openlanguageprofiles/olp-en-cefrj) (Tono Laboratory, Tokyo University of Foreign Studies). Переводы, примеры и формы написаны с помощью Claude и проверены автоматически и выборочно.

## Запуск в Telegram (один раз, около 15 минут)

### Шаг 1. Выложить сайт на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com), если аккаунта нет.
2. Нажмите **+** справа вверху → **New repository**.
3. Имя: `english-trainer`. Выберите **Public** (бесплатный GitHub Pages работает только с публичными репозиториями). Нажмите **Create repository**.
4. На странице репозитория нажмите ссылку **uploading an existing file**.
5. Перетащите в окно **содержимое** распакованной папки (`index.html`, `style.css`, `app.js` и остальное; папки не нужны, всё лежит в корне), а не саму папку. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В блоке **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
7. Через 1–2 минуты сверху появится адрес вида `https://ВАШ_ЛОГИН.github.io/english-trainer/`. Откройте его в браузере и проверьте, что приложение работает.

### Шаг 2. Создать бота и привязать к нему приложение

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Введите отображаемое имя (например, `My English Trainer`), затем username, который заканчивается на `bot` (например, `my_english_trainer_bot`).
3. BotFather пришлёт **токен**. Никому его не показывайте и не вставляйте в код. В версии 1 он не нужен, понадобится в v3 для напоминаний.
4. Отправьте `/mybots` → выберите бота → **Bot Settings** → **Menu Button** → **Configure menu button**.
5. Пришлите адрес из шага 1, затем название кнопки, например `Учить`.
6. Откройте своего бота: слева от поля ввода появится кнопка **Учить**. Нажмите её — приложение откроется внутри Telegram, а прогресс будет храниться в облаке Telegram.

Если меню BotFather выглядит иначе, ищите пункты **Menu Button** или **Configure Mini App**: Telegram время от времени меняет интерфейс BotFather.

## Как обновлять

Замените изменённые файлы в репозитории (**Add file → Upload files**). GitHub Pages обновится за 1–2 минуты. Прогресс при этом не теряется: он хранится не в файлах, а в облаке Telegram.

### Как выпустить новую версию (для разработчика)

1. Добавьте запись сверху в `changelog.js`. Нумерация: исправления — 1.2.0 → 1.2.1, новые функции — 1.2.0 → 1.3.0.
2. В `index.html` замените все `?v=…` на новый номер. По нему Telegram понимает, что файлы нужно скачать заново. `check.sh` не даст забыть.
3. Запустите `./check.sh` и загрузите файлы сайта. Пользователи, которые уже заходили, увидят окно «Что нового».

## Проверка перед обновлением (для разработчика)

```sh
./check.sh
```

Нужны Node.js и Python с Playwright (`pip install playwright && python3 -m playwright install chromium`).
