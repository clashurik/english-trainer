# Формат карточки словаря (для людей и агентов)

Словарь хранится в `data/*.json`: каждый файл — JSON-массив объектов. Из них скрипт `tools/build_words.py` собирает `words.js`, который и загружает приложение.

## Поля

```json
{
  "en": "decide",
  "ru": "решать, принимать решение",
  "pos": "v",
  "lvl": "A2",
  "ex": [
    ["We decided to stay at home.", "Мы решили остаться дома."],
    ["Have you decided what to order?", "Ты уже решил, что будешь заказывать?"],
    ["It's hard to decide between these two jobs.", "Трудно выбрать между этими двумя работами."]
  ],
  "forms": [["decision", "n", "решение"], ["decisive", "adj", "решительный"], ["decisively", "adv", "решительно"]],
  "note": "make a decision (не do a decision) — принять решение"
}
```

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `en` | да | Слово или выражение. Глагол — без `to`. Британское написание (colour, centre, travelled). |
| `ru` | да | 1–3 коротких перевода через запятую. Уточнение в скобках при необходимости. Неправильное множественное число: `ребёнок (мн. ч. children)`. |
| `pos` | да | `n` существительное, `v` глагол, `adj` прилагательное, `adv` наречие, `ph` фраза / фразовый глагол / выражение из нескольких слов. |
| `lvl` | да | `A1`, `A2`, `B1` или `B2`. |
| `ex` | да | Ровно 3 примера: пары [английское предложение, русский перевод]. |
| `irr` | только для неправильных глаголов | Вторая и третья формы через `|`: `"went|gone"`. Если вариантов два: `"learnt/learned|learnt/learned"`. Для правильных глаголов и не-глаголов поле не пишется. |
| `forms` | да (может быть `[]`) | Однокоренные слова других частей речи: [слово, часть речи, перевод]. 0–4 штуки. |
| `gram` | да (может быть `[]`) | Грамматические формы самого слова: [форма, код] или [форма, код, уточнение]. Коды и правила — ниже. |
| `note` | нет | Короткая подсказка на русском, только если она правда полезна: ложный друг переводчика, частая ошибка, управление (`depend on`, не `depend from`), отличие от похожего слова. Не больше чем у каждой пятой карточки. |

## Требования к примерам

- Естественный современный английский, взрослая повседневная жизнь: работа, учёба, дом, друзья, поездки, покупки, здоровье, телефон и интернет. Без детских и учебниково-скучных фраз вроде «This is a cat».
- 5–14 слов. Лексика не сложнее уровня самого слова.
- В каждом примере есть само слово (в любой форме: decided, children, went).
- Три примера разные: разные ситуации и разная грамматика (утверждение, вопрос, отрицание, прошедшее время). Если у слова несколько частых значений, перечисленных в `ru`, примеры показывают разные значения.
- Русский перевод естественный, как сказал бы носитель, а не дословный.
- Никаких реальных знаменитостей, брендов, политики, грубостей.

## Грамматические формы (`gram`)

Формы, в которых само слово встречается в речи. Приложение показывает их по нажатию на слово и по ним же находит слово в примерах, чтобы подсветить его.

| Код | Что это | Пример |
| --- | --- | --- |
| `pl` | множественное число существительного | `["children", "pl"]`, `["days", "pl"]` |
| `unc` | существительное неисчисляемое, форма пустая | `["", "unc"]` для money, advice, information |
| `s3` | глагол с he/she/it | `["changes", "s3"]`, `["goes", "s3"]` |
| `ing` | форма на -ing | `["changing", "ing"]`, `["stopping", "ing"]` |
| `pastpp` | прошедшее время и причастие правильного глагола (V2 = V3) | `["changed", "pastpp"]`, `["tried", "pastpp"]` |
| `comp` | сравнительная степень | `["bigger", "comp"]`, `["more expensive", "comp"]` |
| `sup` | превосходная степень | `["the biggest", "sup"]`, `["the most expensive", "sup"]` |
| `past`, `pp` | только для фраз с неправильным глаголом | `["gave up", "past"]`, `["given up", "pp"]` |

Правила:
- `n` — `pl`, если слово исчисляемое; `unc`, если обычно неисчисляемое. Если у слова оба употребления, `pl` с уточнением: `["times", "pl", "= раз; времена"]`.
- `v` — `s3`, `ing` и, если глагол правильный, `pastpp`. У неправильных глаголов V2 и V3 уже есть в `irr`, в `gram` их не дублировать.
- `adj` — `comp` и `sup`, если прилагательное сравнивается; для несравниваемых (main, dead, daily) — `[]`.
- `adv` — `comp`/`sup` только если они употребительны (fast → faster, often → more often); иначе `[]`.
- `ph` — для фраз с глаголом: формы глагольной части. Правильный глагол: `["looked after", "pastpp"]`, `["looking after", "ing"]`. Неправильный: `["gave up", "past"]`, `["given up", "pp"]`, `["giving up", "ing"]`. Для выражений без глагола и готовых реплик (by the way, How are you?) — `[]`.
- Уточнение (третий элемент) — по-русски и коротко, только когда без него непонятно.

## Требования к формам (`forms`)

- Только реальные и употребительные однокоренные слова **другой** части речи или заметно другого значения: decide → decision, decisive; happy → happiness, happily, unhappy; teach → teacher.
- Не грамматические формы того же слова (decides, decided, cats, better) — их не включать.
- Неправильные глаголы получают поле `irr`, а не `forms`.
- Если подходящих слов нет — `[]`. Лучше пусто, чем выдуманное слово.
